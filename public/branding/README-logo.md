# Email Automator logo assets

## Concept
Three arbitrary data inputs converge into a single mail/send symbol:
- left nodes = arbitrary spreadsheet schemas / rows / sources
- convergence = deterministic merge and mapping
- right arrow-envelope = personalized email dispatch
- compact rounded tile = safe, inspectable workflow
